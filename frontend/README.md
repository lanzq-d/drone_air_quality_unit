# 前端页面

前端是无构建步骤的静态页面，既可以由 `backend/server.js` 在电脑上托管，也可以后续压缩后放进 ESP32 固件。

默认每秒请求一次：

```text
/api/latest
```

页面包含：

- TVOC、CH2O、CO2、DC01 关键读数
- GPS 定位状态、经纬度、卫星数、速度
- 三个模块的在线状态、帧数和错误数
- 指标参考范围、颜色状态、趋势图和综合判断

## 设计目标

页面按“电脑调试优先，手机现场查看可用”设计：

- 电脑端用于开发和地面测试，展示趋势、定位、模块状态。
- 手机端用于连接 ESP32 SoftAP 后快速查看当前读数和综合结论。

空气质量监测不建议只显示原始数据。当前页面同时给出参考范围、趋势图和综合分析，便于判断某个数值是偶发波动还是持续异常。
