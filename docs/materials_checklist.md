# 开工前资料与器件清单

## 已有器件

- [x] ESP32-WROOM-32 开发板
- [x] TVOC-CO2 三合一模块
- [x] DC01 粉尘模块
- [x] GY 系列 NEO-M8N GPS 开发板
- [x] GPS 天线
- [x] 无人机电池及分电盘

## 必须确认或补充

- [ ] 无人机动力电池实际节数和最大电压
- [ ] 分电盘是否已有稳定 5 V 输出
- [ ] GPS 开发板 VCC 是否带板载 5 V 转 3.3 V 稳压
- [ ] DC01 实际接口线序
- [ ] TVOC 模块实际接口线序
- [ ] DC01 上电后的实际输出模式
- [ ] TVOC 和 DC01 TX 高电平实测值

## 正式采集建议补购

- [ ] 输入覆盖电池最大电压、输出 5 V、额定至少 2 A 的 DC-DC 降压模块
- [ ] 3.3 V/5 V UART 电平转换器，至少两路输入转换
- [ ] 2.54 mm 和 1.5 mm 连接线或转接线
- [ ] 保险或可恢复保险器件
- [ ] 传感器固定支架和防振安装件
- [ ] 适合传感器进气的防护罩

## 不作为硬件前置条件

- 独立温湿度传感器
- SD 卡
- 4G/LoRa 模块
- 外部服务器
- 飞控姿态或电机控制接口
