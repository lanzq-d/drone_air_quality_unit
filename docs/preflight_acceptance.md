# 开发前验收顺序

## 阶段 1：主控

1. USB 连接 ESP32。
2. 烧录最小程序。
3. 串口输出芯片启动信息。
4. 建立临时 SoftAP。
5. 手机或电脑访问测试页面。

## 阶段 2：GPS

1. GPS 天线朝上。
2. GPS 接 5 V、GND、TX、RX。
3. 读取 NMEA 原始字符串。
4. 室外等待定位。
5. 验证经纬度、时间和卫星数量。

## 阶段 3：TVOC

1. 仅给 TVOC 稳定供电。
2. 等待预热。
3. 测量 TX 高电平。
4. 只有确认电平安全或接入电平转换后，才接 ESP32。
5. 校验 9 字节数据帧和校验和。

## 阶段 4：DC01

1. 仅给 DC01 稳定供电。
2. 确认其输出为 UART 而非 PWM。
3. 测量 TX 高电平。
4. 接入电平转换后读取 4 字节帧。
5. 验证 `0xA5` 帧头和校验和。

## 阶段 5：集成

1. 三类数据同时读取。
2. 断开某一传感器，验证离线状态。
3. Wi-Fi 断开后验证本地缓存。
4. 长时间静态运行。
5. 最后再进行旋翼静态测试。
